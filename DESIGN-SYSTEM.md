# DESIGN SYSTEM – BHARATBRIDGE

## 1. Design Overview
BharatBridge uses a clean, modern and minimal interface with a professional appearance. The design combines an earthy colour palette with simple layouts to reflect Indian businesses while maintaining a global identity.

## 2. Colour Palette

| Colour | Hex Code | Usage |
|---|---|---|
| Primary | `#183C32` | Main buttons and primary elements |
| Secondary | `#DDE8DF` | Secondary backgrounds and highlights |
| Background | `#F7F4ED` | Main page background |
| Text | `#252B28` | Main text |
| Accent | `#D6A65D` | Highlights and accent elements |
| Muted | `#777F78` | Secondary text |
| Border | `#E7E4DB` | Card and section borders |

## 3. Typography

**Font Family:** Arial, Helvetica, sans-serif

The interface uses a simple sans-serif font to maintain readability and consistency across different sections.

## 4. Layout and Navigation

The application uses a sidebar-based navigation layout with a main content area.

The sidebar provides access to:
- Overview
- My Products
- Market Explorer
- Readiness Centre
- Cost Planner
- Buyer Profile

A header provides page-level navigation and information.

## 5. UI Components

The main reusable interface elements include:

- **Cards:** Display products, statistics and important information.
- **Buttons:** Allow users to perform actions such as adding products and updating information.
- **Input Fields:** Collect product, business and cost details.
- **Dropdowns:** Allow users to select products and target markets.
- **Checkboxes:** Track preparation tasks.
- **Progress Indicators:** Display readiness checklist completion.
- **Forms:** Allow users to enter and edit information.

## 6. User Interactions

BharatBridge includes interactive elements such as:
- Adding, searching and deleting products.
- Switching between the UAE and USA markets.
- Updating readiness checklist tasks.
- Editing values in the cost planner and viewing calculated results.
- Editing and previewing the buyer profile.
- Saving product and readiness information using browser local storage.

## 7. Design Principles

The interface follows these principles:

1. **Simplicity:** Keep navigation and actions easy to understand.
2. **Consistency:** Maintain consistent colours and interface elements.
3. **Readability:** Use clear typography and suitable spacing.
4. **Usability:** Make important features easy to access.
5. **Professional Appearance:** Create a clean interface suitable for business users.
